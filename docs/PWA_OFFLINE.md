# ShotMeld PWA 离线功能说明

## 功能特性

### 🌐 离线浏览
- **自动缓存**: 浏览过的照片和相册会自动缓存到本地
- **离线访问**: 断网时可以继续浏览已缓存的内容
- **智能提示**: 实时显示网络状态和缓存数据状态

### 📱 Progressive Web App (PWA)
- **桌面安装**: 可以像原生应用一样安装到桌面
- **离线优先**: 优先使用缓存，网络作为补充
- **自动更新**: 检测到新版本时自动提示更新

### 💾 数据管理
- **IndexedDB 存储**: 使用浏览器本地数据库存储数据
- **自动清理**: 定期清理过期的缓存数据（7天）
- **操作队列**: 离线时的操作会排队，网络恢复后自动同步

## 使用方法

### 首次使用
1. 访问网站并正常浏览照片和相册
2. 系统会自动缓存浏览过的内容
3. 当网络断开时，会显示离线指示器

### 离线浏览
- 断网时右上角会显示"离线模式"提示
- 可以继续浏览已缓存的照片和相册
- 搜索功能在离线时仅限于已缓存的内容

### 离线操作
- 删除、编辑等操作会被暂存
- 网络恢复后会自动同步这些操作
- 操作成功后会显示同步完成提示

### 安装为应用
1. 在支持PWA的浏览器中访问网站
2. 浏览器会提示"安装应用"
3. 安装后可以像原生应用一样使用

## 技术实现

### 缓存策略
- **静态资源**: 预缓存所有JS、CSS、图标等文件
- **API请求**: NetworkFirst策略，优先网络，失败时使用缓存
- **图片**: CacheFirst策略，优先使用缓存，减少加载时间
- **字体**: 长期缓存策略，减少重复下载

### 数据存储
- **Service Worker**: 处理网络请求和缓存管理
- **IndexedDB**: 存储照片、相册等结构化数据
- **Cache API**: 存储静态资源和API响应

### 同步机制
- **后台同步**: 网络恢复时自动执行待同步操作
- **冲突解决**: 智能处理本地和服务器数据冲突
- **错误重试**: 失败的操作会自动重试

## 浏览器支持

### 完全支持
- Chrome 67+
- Firefox 61+
- Safari 11.1+
- Edge 79+

### 部分支持
- 旧版浏览器支持基础功能
- 不支持PWA的浏览器仍可正常使用

## 存储空间

### 预估占用
- 基础应用: ~5MB
- 100张照片缓存: ~50MB
- 数据库索引: ~1MB

### 清理机制
- 自动清理超过7天的缓存
- 手动清理功能（设置页面）
- 浏览器存储配额管理

## 注意事项

### 隐私保护
- 所有数据仅存储在本地设备
- 不会上传缓存数据到服务器
- 支持完全清除本地数据

### 性能影响
- 首次访问可能略慢（建立缓存）
- 后续访问显著加快
- 离线时响应接近即时

### 更新机制
- 检测到新版本时会提示更新
- 更新过程中保留用户数据
- 支持强制刷新获取最新版本

## 故障排除

### 缓存问题
- 刷新页面重新加载资源
- 清除浏览器缓存
- 重新安装PWA应用

### 同步问题
- 检查网络连接
- 等待自动重试
- 手动刷新页面触发同步

### 存储问题
- 检查浏览器存储空间
- 清理不必要的缓存数据
- 重置应用数据
